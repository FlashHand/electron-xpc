# xpc-001 — Green build with real electron types

## Objective

Make `yarn build` and a new `yarn typecheck` both exit 0, using **real** Electron types instead of the
hand-rolled stub, and remove stale build output. Satisfies R5.

`yarn build` is currently red on `main`:

```text
src/main/xpcMain.helper.ts(1,10): error TS2305: Module '"electron"' has no exported member 'utilityProcess'.
src/main/xpcMain.helper.ts(1,26): error TS2305: Module '"electron"' has no exported member 'MessageChannelMain'.
src/main/xpcMain.helper.ts(74,10): error TS2503: Cannot find namespace 'Electron'.
src/main/xpcMain.helper.ts(130,37): error TS2503: Cannot find namespace 'Electron'.
```

Cause: `src/typings/electron.d.ts` is a hand-written `declare module 'electron'` stub covering only
`ipcMain` / `ipcRenderer` / `webContents` / `contextBridge`. It predates the utility-process code and
lacks `utilityProcess`, `MessageChannelMain`, `MessagePortMain`, and the global `Electron` namespace.
The committed `dist/` was produced on a machine that happened to have `electron` installed.
