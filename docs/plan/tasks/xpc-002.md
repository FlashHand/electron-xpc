# xpc-002 — One stable portId per utility process

## Objective

Give each utility process a single stable identity, minted at fork, and stop `subscribe()` from
writing to the handler registry. Satisfies R2, R3, R4 and restores invariants 2 and 3.

Root cause and the three resulting defects:
[../../issues/utility-subscribe-hijacks-handler-registry.md](../../issues/utility-subscribe-hijacks-handler-registry.md)

## Context

- [../../architecture/README.md](../../architecture/README.md) — §Port identity, §Routing: broadcast / subscribe, §Invariants
- [../../issues/utility-subscribe-hijacks-handler-registry.md](../../issues/utility-subscribe-hijacks-handler-registry.md)

## Required design

`xpcCenter` API change — identity and ownership become separate operations:

| Before | After |
|---|---|
| `registerPortHandler(handleName, port2) → portId` (mints an id, writes registry **and** port map) | `registerPort(port) → portId` (mints an id, writes port map only) |
| | `registerPortHandler(handleName, portId) → void` (writes registry only, never mints) |
| `findPortId(port)` linear scan over `port2Map` | `findPortId(port)` O(1) via `WeakMap<MessagePortMain, string>` |

`createUtilityProcess()` mints the id once, before `port2.start()`, and closes over it:

```text
const { port1, port2 } = new MessageChannelMain();
const portId = xpcCenter.registerPort(port2);        // ← exactly once, before any message
const child = utilityProcess.fork(...);
child.postMessage({ type: 'xpc:init' }, [port1]);
port2.on('message', ...)   // all branches use the closed-over portId
port2.start();
```

Branch behavior after the change:

| Message | Effect |
|---|---|
| `__xpc_register__` | `xpcCenter.registerPortHandler(handleName, portId)` |
| `__xpc_subscribe__` | `xpcCenter.addSubscriber(handleName, { type: 'port', id: portId })` — **registry untouched** |
| `__xpc_broadcast__` | `xpcCenter.broadcast(payload.handleName, payload.params, { type: 'port', id: portId })` — no `if (senderPortId)` guard, the id always exists |
| `__xpc_finish__` | unchanged |

Keep `findPortId()` exported even though `createUtilityProcess()` no longer needs it — it is public
API on `xpcCenter`. Reimplement it over the `WeakMap`; do not delete it.
