## Breaking-change note

`xpcCenter.registerPortHandler(handleName, port2)` became
`registerPortHandler(handleName, portId)`, and `xpcCenter.registerPort(port)` is new (xpc-002).
`xpcCenter` is exported from `electron-xpc/main`, so record this in the README's API surface even
though these methods are internal by intent. `1.2.0` is acceptable for it: no documented consumer API
changed, only an undocumented internal on an exported singleton.
