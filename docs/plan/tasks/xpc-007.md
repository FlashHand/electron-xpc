| Finding | Fix |

| P3-1 context outlives the call in timers | documented: read at handler entry |
| P3-2 a forgotten caller defaulted to `main` | internal entries use `execAs` with a required caller |
| P3-3 caller is only the most recent hop | documented |
| P3-4 doc drift | READMEs: thirteen harness cases, `yarn test:unit`, *Changes in 1.3.0*, full-width punctuation in the CN section |

uses real ids so it exercises the `!caller.frame` guard; the utility `portId` is asserted against the

"same-site" with a `loadFile` note, plus code called directly from a handler; T13 got its own harness group.
