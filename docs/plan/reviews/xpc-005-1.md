## Log relay acyclicity

Three sources, one direction each:

| Source | To screen | To terminal |
|---|---|---|
| main | `broadcast('log/line')` → renderer subscriber | `console.log` in `emit()` |
| utility | `child.stdout` → main's `emit()` → same broadcast | main's `console.log` |
| renderer | local `append()` | `send('log/append')` → main prints, **does not** re-broadcast |

The renderer never re-emits what it receives on `log/line`, and main's `log/append` handler only
prints. No path returns a line to its own producer.
